# Chrolo 0.2.0a1 experimental alpha

Chrolo turns a reproducible agent failure into a reduced input fixture and a
pytest regression that exercises the application code. It is MIT licensed and
requires Python 3.10 or newer.

## What is included

- Failure-preserving event reduction with explicit dependencies and a precise
  Python failure oracle.
- Graph-compatible capture, strictly matched JSON boundary cassettes, and
  `chrolo prepare` to create a verified local regression bundle.
- Buffered synchronous OpenAI Responses, Chat Completions, and Anthropic
  Messages adapters; optional LangGraph and LangChain integration.
- Trace inspection, heuristic scanning, sanitization, and a local Trace Desk.
- Separate isolated Docker replay for recorded OpenHands actions and source
  repairs after those actions.

The real-action regression gate has 28 passing checks across PyHOCON, Vermouth,
and PyFilesystem. The PyFilesystem screen retains two negative outcomes as well
as one failure reduced from 59 actions to four. These are selected tasks with
explicit fixture limitations, not a corpus-wide reliability estimate.

## Getting started

For the release, clone the repository and check out `v0.2.0a1`, create
a virtual environment, and run:

```bash
python -m pip install -e '.[dev]'
python -m chrolo --version
```

Follow the [quickstart](https://github.com/SanjayKarun4444/chrolo/blob/v0.2.0a1/README.md#quickstart) to capture the included
synthetic failure and generate a test. It needs no model key. The first test
run intentionally fails; fixing the application makes the same test pass.

Wheel and source-archive installation are also supported. No PyPI upload is
implied by a GitHub release; source installation is the documented default.
If moving from a local development build labeled `0.2.0`, use a fresh
environment or explicitly reinstall: `0.2.0a1` sorts below `0.2.0`.

## Alpha scope

APIs and trace formats may change. Replay covers only explicitly wrapped
calls; graph code can still perform unwrapped effects. Async, streaming,
arbitrary capture, and SDK response reconstruction are unsupported. Captures
may contain confidential data; generated code must be trusted. Raw real-agent
fixtures are not included in the package.

See [CHANGELOG.md](https://github.com/SanjayKarun4444/chrolo/blob/v0.2.0a1/CHANGELOG.md), [SECURITY.md](https://github.com/SanjayKarun4444/chrolo/blob/master/SECURITY.md), and the
[benchmark guide](https://github.com/SanjayKarun4444/chrolo/blob/v0.2.0a1/benchmarks/README.md) for details. Report ordinary bugs
using a small synthetic example and keep vulnerability details private.
